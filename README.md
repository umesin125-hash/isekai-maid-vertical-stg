# 異世界メイドはまさかの俺⁈ 縦スクゲーのアソビカタ

**縦スクロール弾幕シューティングゲーム｜試作版 Ver.0.1.0**  
**原作・企画：梅酢（UMEZU）**

> ライトノベル『異世界メイドはまさかの俺⁉︎ 並行世界へのカエリカタ』の世界観をもとに制作した、縦画面専用の弾幕シューティングゲームの試作版です。  
> 3人の主人公級キャラクターを選び、魔法と魔力量子の力で空を駆け、魔物と魔導兵器に挑みます。

## 遊び方

1. タイトル画面で **PUSH START** を押します。
2. **アリステア／ミリア／カナト** の3人から操作キャラクターを選びます。
3. **ゲーム開始** を押すと、自機が画面下から登場します。
4. 自機を動かして敵弾を避けながら、自動で発射されるショットで敵を倒します。
5. 敵が落とす **P（パワーアップ）** と **B（ボム補充）** を回収して強化します。
6. **ザコ敵 → 中ボス → ザコ敵 → 大ボス** の順で戦い、大ボスを倒すとステージクリアです。

### スマートフォン操作

| 操作 | 内容 |
| --- | --- |
| 画面内をタッチしてなぞる | 自機を上下左右に移動（指の移動量に追従） |
| ショット | 自動連射。攻撃ボタンの操作は不要 |
| 右下の **BOMB** | ボムを1個消費して周囲に攻撃し、敵弾を消去 |
| 右上の一時停止ボタン | ポーズメニューを表示 |
| キャラクター選択画面のカード | タップで自機を切り替え |

※画面をタップした位置へ自機が瞬間移動する方式ではなく、タッチ後の指の移動量に応じて動きます。  
※縦画面でのプレイを想定しています。音声再生は、ブラウザの仕様上、最初のタップ操作後に有効になります。

## 操作キャラクター

| キャラクター | バトルタイプ | 通常ショット | 特徴 |
| --- | --- | --- | --- |
| **アリステア・ミリオーネ** | 広範囲・安定型 | 《光の棘》 | 黄金の魔法弾を広げて撃つ、扱いやすい万能タイプ |
| **ミリア・レフス** | 近接高火力・技巧型 | 【鋼志】の斬衝撃波 | 青い弧状の斬撃。遠くへ進むほど斬撃が小さくなる |
| **カナト・ルクス** | 直線集中・高機動型 | 魔導リボルバー | 高速連射で正面を攻撃する、移動速度の高いタイプ |

各自機には、**固有色のオーラ、背面で回転する魔法陣、銀色の魔力量子エフェクト**があります。自機中央の**虹色の点**が敵弾に対する小さな当たり判定の目安です。

## パワーアップとアイテム

- **POWER（P）**：ショットが1段階強化されます。初期値は **1/5**、最大 **5/5**。パワーが上がると同時発射数が増えます。
- **BOMB（B）**：ボムの所持数が1個増えます。初期所持数は **3個**、最大 **6個**。
- 中型の強化敵がパワーアップ／ボム補充アイテムを落とします。中ボス撃破時にも報酬が出現します。
- 敵弾に被弾すると残機が1減り、パワーは最低1まで1段階低下します。残機が0になるとゲームオーバーです。
- ボムを使うと敵弾が消去され、敵へダメージを与え、短い無敵時間を得られます。

## ゲーム画面の見方

| 表示 | 意味 |
| --- | --- |
| `SCORE` | 獲得スコア |
| `GRAZE` | 敵弾をかすめた回数（加点あり） |
| `STAGE` | 現在の進行状況 |
| `♥` | 残機数 |
| `POWER`／`PWR` | ショットの強化段階（1〜5） |
| `BOMB ×n` | ボム残数と発動ボタン |
| ボスHPゲージ | 中ボス／大ボスの残り耐久力 |

## GitHub Pagesで遊ぶ・公開する

### 1. ファイルを配置

このリポジトリのルート（最上位）に **`index.html`** を配置してください。

```text
リポジトリ/
├── index.html
└── README.md
```

試作版はHTML単体で動くため、追加の画像ファイルやMP3ファイルは必須ではありません。

### 2. GitHub Pagesを設定

1. GitHubでリポジトリを作成し、**Public** に設定します。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment** で `Deploy from a branch` を選びます。
4. Branchを `main`、フォルダを `/(root)` にして **Save** を押します。
5. Pagesで表示された公開URLをスマートフォンやPCのブラウザで開きます。

※公開URLは各リポジトリで異なります。公開URLの発行までは少し時間がかかる場合があります。

### 3. ファイルを直接開く場合

`index.html` を対応ブラウザで開いてプレイできます。端末によってはローカルファイルの扱いに制限があるため、**GitHub PagesなどのHTTPS環境で開く方法を推奨**します。
